## STM32CubeIDE / FreeRTOS 移植边界

源码在 src/c3_cell/firmware。kin.c 是纯 C 正逆解，controller 外环、通信协议及失联自锁可在主机编译。h743_port.c 是 FreeRTOS 任务和 EXTI 入口，servo_fd.c 实现六帧缓存后同步提交，board_reference.c 提供参考 ADC、GPIO 和 FDCAN2 反馈接入。

1. 根据实际 H743 封装、板卡原理图建立 CubeMX 工程，选择匹配的 HSE、PLL、启动文件和链接脚本，配置两个 FDCAN、收发器、滤波器、发送 FIFO、ADC DMA、GPIO 和 FreeRTOS 1 kHz 时基。
2. 添加 firmware 的 C/H 文件和 libm；在 CubeMX 的 main.h 中映射 ESTOP、LIMIT_ANY、INFEED、DRIVE_ENABLE 引脚。参考板级文件将六轴限位合并为保护输入；具体轴号、方向和回零序列需要按实物实现。
3. 按实物填写采样比例和零点宏，提供 c3_adc_dma[2]。H7 的 DMA 内存须按芯片缓存配置处理。输入电平极性必须对应真实常闭回路和辅助触点。
4. 启动 CAN、ADC 和驱动回报后，确认板上已有完整新鲜反馈再启动运动任务。没有合法反馈会锁存故障。驱动上电许可、安全复位和硬件使能由板级联锁管理，示例没有自动拉高动力使能。
5. 独立安全链能在 PC、ROS 或 MCU 失效时切断危险运动。控制器周期、仿真接触停机、软件限位及热插拔重连均不能用于证明真机安全等级。
6. 完成单轴方向/零位标定、六轴同步验收、TCP 与相机外参标定、工具压力与扭矩校准，再做带载重复定位测试。项目未包含该板厂启动工程、商业伺服固件、生产 PCB Gerber 或安全认证。
