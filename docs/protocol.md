# C3-FD v1 总线协议

## 物理拓扑与周期

工控机运行 ROS 2 调度和 MoveIt。以太网连接支持 Linux SocketCAN 网络设备的 CAN FD 网关；网关 FD 端接 H743 的 FDCAN1。H743 的 FDCAN2 接六关节和夹具控制器。网关必须能在 Linux 端提供 can0 或等效网络设备。厂商只提供 UDP SDK 的型号需单独适配。仿真时 Gazebo 世界插件取代网关与实体控制板，在 ROS 话题里传递逐字节相同的 48 字节负载。

上层 100 Hz 下发目标、读取反馈；控制板 1 kHz 计算位置外环；参考下游 200 Hz 分发六轴影子寄存器并同步提交。时间戳为各端单调时钟毫秒数，不作跨端绝对时间。工程示例选择 1 Mbit/s 仲裁、5 Mbit/s 数据段作为台架设计输入；时序、收发器、线长、总线负载、驱动支持需实测。ROS2 的调度节点运行在工控机，以太网承载网关通信。

## 上游 48 字节，标准 11 位 ID，CAN FD + BRS，小端

|偏移|宽度|字段|约定|
|---:|---:|---|---|
|0|1|版本|1|
|1|1|帧型|1 命令 ID 0x180，2 反馈 ID 0x280|
|2|2|序号|uint16，65535 后回到 0，控制板拒绝重复和旧序号|
|4|4|时钟|uint32 毫秒|
|8|24|q1…q6|六个 int32，微弧度，命令是目标，反馈是测量值|
|32|2|夹爪|单指相对最小开口的行程，μm，范围 0…16000；两指最小内间距 30 mm|
|34|2|IO|见下表|
|36|2|故障|按位组合|
|38|1|flags|命令 bit0 使能许可，bit1 急停请求。反馈预留|
|39|7|预留|发送端置零|
|46|2|CRC|CRC-16/CCITT-FALSE，初值 FFFF，多项式 1021，覆盖 0…45；低字节在前|

|IO 位|命令|反馈|
|---|---|---|
|0|夹持请求|工件已连接 / 夹具确认|
|1|预留|两指到位或接触|
|2|允许工艺规定的工件与支撑面接触|预留|
|3|预留|进料光电有效|
|4|压合请求|压力进入窗口|
|5|锁付使能|锁付完成|

PC 网关非阻塞收发，断链后按 1 s 间隔重开 SocketCAN。应用层对超过 0.5 s 的反馈超时锁存停机；MCU 对失联超过 100 ms 锁存。通信恢复只恢复数据流。台架仿真与实机日志都记录原始 TX、RX 十六进制和测量关节角度。同一 ROS 域只启动一个命令生产者。

## 下游参考伺服契约

|ID|长度|格式|
|---|---:|---|
|0x201…0x206|8|uint16 epoch，int32 目标速度 μrad/s，CRC16|
|0x207|8|epoch，uint16 单指开口 μm，uint16 工艺 IO，CRC16|
|0x080|8|epoch，四字节零，CRC16；驱动执行当期缓存|
|0x281…0x286|16|int32 位置 μrad，int32 速度 μrad/s，int16 电流 mA，4 字节预留，CRC16|
|0x287|16|uint16 单指位置 μm，uint16 反馈 IO，10 字节预留，CRC16|

FDCAN2 配置发送 **FIFO**，保证同一控制器已排入的分轴帧先于 SYNC。任一分轴入队失败跳过 SYNC 并锁存通信故障。每个驱动只提交匹配 epoch 的完整指令。此契约由本项目定义，采购时必须拿已选电机协议核对；CANopen、CiA 402 或厂家私有协议需替换 servo_fd.c 和对应反馈解析。硬件端真实收到的电机反馈应至少满足 40 ms 新鲜度要求，夹具反馈为 50 ms。
